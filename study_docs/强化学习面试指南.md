# 一、RL 基础概念（必问）

## Q1 ★ 什么是强化学习？和监督学习、无监督学习有什么区别？

**标准答案**

| 维度 | 监督学习 | 强化学习 |
|---|---|---|
| 学习信号 | 每张样本的标注（标准答案） | 稀疏、延迟的奖励信号 |
| 数据分布 | 预先给定的 i.i.d. 数据 | 由当前策略与环境交互产生，非 i.i.d.、序列相关，且分布随策略变化 |
| 目标 | 最小化预测误差 | 最大化长期累计回报 |
| 反馈性质 | 即时、密集 | 延迟（credit assignment 难） |

RL 的三个核心难点（主动说出显得有体系）：
1. **信用分配（credit assignment）**：一步奖励要归因到很早之前的哪个动作？
2. **探索-利用权衡（exploration-exploitation）**：数据是自己采的，不探索就永远不知道更好的动作。
3. **分布随策略变化**：训练数据分布非平稳，是深度 RL 不稳定的根源之一。

**一句话总结**：监督学习学"标准答案是什么"，强化学习学"什么行为长期回报最大"，数据要自己边试边采。

## Q2 ★ MDP 五元组是什么？马尔可夫性质？不满足怎么办？

**标准答案**

MDP 的五元组：$(S, A, P, R, \gamma)$。

**符号说明**：$S$ 是状态空间，$A$ 是动作空间，$P$ 是转移概率，$R$ 是奖励函数，$\gamma \in [0,1]$ 是折扣因子。$s$ 和 $s'$ 分别表示当前、下一状态，$a$ 是当前动作；$P(s' \mid s,a)$ 是给定 $s,a$ 后到达 $s'$ 的概率，$R(s,a)$ 是对应的奖励函数值。

马尔可夫性质，即"未来只依赖当前状态和动作，与历史无关"：

$$
P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \ldots)
= P(s_{t+1} \mid s_t, a_t).
$$

**符号说明**：$t$ 是当前时间步；$s_t,a_t$ 是这一步的状态和动作，$s_{t+1}$ 是下一状态，$s_{t-1},a_{t-1},\ldots$ 是更早的历史。$P(\cdot\mid\cdot)$ 表示条件概率，竖线右侧是已知条件。

不满足马尔可夫性 → 退化为 POMDP（部分可观测 MDP，七元组：再加观测空间 Ω、观测函数 O、信念状态）。工程上的处理手段：
- **frame stacking**：Atari 单帧画面看不出球的速度，叠 4 帧即可近似马尔可夫；
- **补全状态**：机器人只给关节位置看不出速度 → 加历史帧或显式估计速度；
- **RNN / Transformer** 编码历史（DRQN）；
- 维护 belief state。

**加分项**：legged_gym 里 obs 包含"上一帧动作"，除了平滑作用，也有补全状态（近似动作的历史效应）的意味。

**一句话总结**：马尔可夫性是理论假设，工程上靠"把缺失信息塞进观测"来近似满足。

## Q3 折扣因子 γ 的作用？γ=0 和 γ=1 意味着什么？实际怎么取？

**标准答案**
- 数学上：保证无限时域（infinite horizon）下回报收敛；
- 意义上：未来不确定性折现，$\gamma$ 越小越短视；
- 算法上：$\gamma$ 小 → 目标方差小、收敛快，但策略短视次优；$\gamma$ 大 → 考虑长远，但 credit assignment 难、bootstrap 误差传播远。

$\gamma=0$：纯贪心即时奖励；$\gamma=1$：回合制任务中等于 undiscounted total reward（episodic 任务可取 $1$，continuing 任务必须 $\gamma<1$）。

实际取值：0.99 / 0.995 / 0.999。**有效时间跨度**约为 $1/(1-\gamma)$ 步：$\gamma=0.99$ 时约 100 步。例子：Isaac Gym 腿式机器人 $\Delta t=0.02\,\mathrm{s}$（decimation 为 4，仿真步长为 0.005 秒），$\gamma=0.99$ 对应约 2 秒的有效视野。

**符号说明**：$\gamma$ 是每过一步对未来奖励施加的折扣；$\Delta t$ 是一次策略动作到下一次策略动作之间的时间，即控制周期，$\mathrm{s}$ 是单位「秒」。

**一句话总结**：γ 是"看得多远"的旋钮，取多大取决于任务的因果链条有多长。

## Q4 ★ V 函数和 Q 函数的定义与关系？优势函数？

**标准答案**

- 状态价值函数：$V^\pi(s)=\mathbb{E}_\pi[G_t \mid s_t=s]$，其中 $G_t=\sum_k \gamma^k r_{t+k}$。
- 动作价值函数：$Q^\pi(s,a)=\mathbb{E}_\pi[G_t \mid s_t=s,\ a_t=a]$。
- 关系：$V^\pi(s)=\mathbb{E}_{a\sim\pi(\cdot\mid s)}[Q^\pi(s,a)]$。
- 优势函数：$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$，衡量"这个动作比当前策略的平均水平好多少"。

**符号说明**：$\pi$ 是被评估的策略；$s,a$ 是指定的状态、动作，$s_t,a_t$ 是第 $t$ 步实际访问的状态和选择的动作。$G_t$ 是从第 $t$ 步起的折扣回报；$r_{t+k}$ 是第 $t+k$ 步的奖励，$k$ 从 $0$ 开始计，$\gamma^k$ 是该奖励的权重。$\mathbb{E}_\pi$ 对策略及环境产生的结果求平均；$a\sim\pi(\cdot\mid s)$ 表示在状态 $s$ 按策略抽取动作。

**加分项**：策略梯度里用 A 代替 Q，是因为减掉了状态本身的"基准价值"，只保留动作的相对好坏 → 显著降低方差且不引入偏差。

**一句话总结**：V 是"这个状态有多好"，Q 是"在这个状态做这个动作有多好"，A 是"比平时好多少"。

## Q5 ★ 写出 Bellman 方程（期望形式和最优形式）

**标准答案**

Bellman 期望方程（给定策略 π）：

$$
\begin{aligned}
V^\pi(s)
  &= \sum_a \pi(a \mid s)\sum_{s',r} p(s',r \mid s,a)
     \bigl[r + \gamma V^\pi(s')\bigr], \\
Q^\pi(s,a)
  &= \sum_{s',r} p(s',r \mid s,a)
     \left[r + \gamma \sum_{a'} \pi(a' \mid s')\,Q^\pi(s',a')\right].
\end{aligned}
$$

**符号说明**：$s,a$ 是当前状态和动作，$s',a'$ 是下一状态和下一动作；$r$ 是这一步拿到的奖励，$\gamma$ 是折扣因子。$\pi(a\mid s)$ 和 $\pi(a'\mid s')$ 是策略选相应动作的概率；$p(s',r\mid s,a)$ 是环境在给定 $s,a$ 时同时给出 $s'$ 和 $r$ 的概率。$V^\pi$ 是按策略走的状态价值，$Q^\pi$ 是先做指定动作、再按策略走的动作价值。$\sum_a$ 和 $\sum_{a'}$ 分别枚举当前、下一步的动作，$\sum_{s',r}$ 枚举环境可能给出的状态和奖励组合。

Bellman 最优方程：

$$
\begin{aligned}
V^*(s)
  &= \max_a \sum_{s',r} p(s',r \mid s,a)\,\bigl[r + \gamma V^*(s')\bigr], \\
Q^*(s,a)
  &= \sum_{s',r} p(s',r \mid s,a)\left[r + \gamma \max_{a'} Q^*(s',a')\right].
\end{aligned}
$$

**符号说明**：$V^*(s)$ 是从状态 $s$ 起能取得的最优价值，$Q^*(s,a)$ 是在 $s$ 先做 $a$、之后按最优策略行动的价值；上标 $*$ 表示「最优」。$r$ 是即时奖励，$\gamma$ 是折扣因子；$\sum_{s',r}$ 按 $p(s',r\mid s,a)$ 对环境可能给出的下一状态 $s'$ 和奖励 $r$ 加权。$\max_a$ 在当前状态比较各动作，$\max_{a'}$ 等到下一状态后才比较下一动作。

区别：期望形式对动作取**期望**（评估当前策略），最优形式对动作取 **max**（定义最优策略）。

**一句话总结**：Bellman 方程就是"价值 = 即时奖励 + 折扣后的后继价值"，是所有 value-based 算法的根。

## Q6 策略迭代（PI）和值迭代（VI）的区别？

**标准答案**

| | 策略迭代 | 值迭代 |
|---|---|---|
| 结构 | 策略评估（迭代 Bellman 期望至收敛）+ 策略改进（贪心化），两阶段交替 | 直接迭代 Bellman 最优算子，一步到位 |
| 单步代价 | 评估阶段贵（要收敛） | 便宜 |
| 收敛 | 有限步精确收敛到 $\pi^*$ | 渐近收敛到 $V^*$，再提贪心策略 |

**符号说明**：$\pi^*$ 是最优策略，$V^*$ 是最优状态价值函数。

联系：VI 相当于"评估只迭代一次的截断版 PI"；两者都是广义策略迭代（GPI）的特例，MC/TD 方法也都在 GPI 框架下。

**一句话总结**：PI 是"评准了再改"，VI 是"边评边改"。

## Q7 ★ DP / 蒙特卡洛（MC）/ 时序差分（TD）三者对比

**标准答案**

| | DP | MC | TD |
|---|---|---|---|
| 需要环境模型？ | 需要（已知 P、R） | 不需要 | 不需要 |
| 采样 or 穷举？ | 穷举（宽） | 采样 | 采样 |
| Bootstrapping？ | 是 | 否（用真实回报） | 是 |
| 偏差 / 方差 | —— | 无偏、高方差 | 有偏、低方差 |
| 需要回合结束？ | 否 | 是 | 否，可在线逐步更新 |

TD(0) 更新，括号内是 TD error $\delta$：

$$
V(s) \gets V(s) + \alpha\bigl[r + \gamma V(s') - V(s)\bigr].
$$

**符号说明**：$s$ 是当前状态，$s'$ 是下一状态，$r$ 是这一次转移的实际奖励。$V(s)$、$V(s')$ 是更新前的状态估值；$\gamma$ 是折扣因子，$\alpha$ 是学习率。$\delta$ 是「一步目标减当前估值」，$\gets$ 表示把算出的新估值写回 $V(s)$。

n-step TD 在 MC（$n=\infty$）和 TD(0)（$n=1$）之间插值；TD($\lambda$) 用资格迹（eligibility trace）指数加权所有 n-step。

**符号说明**：$n$ 是目标中使用的真实奖励步数；$\lambda$ 控制不同长度的 n-step 目标的权重。

**一句话总结**：MC 看完整结局再总结，TD 走一步就更新（拿估计当目标），DP 不动腿全靠模型推。

## Q8 ★ On-policy 和 Off-policy 的区别？各举例？

**标准答案**

- **On-policy**：行为策略（采数据的策略）= 目标策略（被评估/改进的策略）。例：SARSA、A2C、PPO（近似，靠 importance ratio 容忍小偏差）。
- **Off-policy**：两者可以不同，能学别人/历史采的数据。例：Q-learning（目标里用 max，与行为策略无关）、DQN、SAC。

对比：

| | On-policy | Off-policy |
|---|---|---|
| 样本效率 | 低（数据用一次就扔） | 高（replay buffer 反复复用） |
| 稳定性 | 较好 | 差（分布偏移 + bootstrapping，见死亡三要素） |
| 能否学历史/他人数据 | 不能 | 能（offline RL 的前提） |

**加分项**：PPO 严格说是 on-policy，但用 $\rho=\pi_{\mathrm{new}}/\pi_{\mathrm{old}}$ 的 importance ratio + clip，让"旧策略数据"服务"新策略更新"，是对 off-policy 修正的保守近似。

**符号说明**：$\rho$ 是同一个状态、同一个已采样动作在新旧策略下的概率比；$\pi_{\mathrm{new}}$ 是更新中的策略，$\pi_{\mathrm{old}}$ 是采集这批数据的策略。连续动作时比较的是概率密度。

**一句话总结**：on-policy 是"自己采的自己用"，off-policy 是"别人采的我也能用"。

## Q9 探索（exploration）有哪些常用策略？

**标准答案**

1. **ε-greedy**：以 ε 概率随机动作，ε 随训练衰减（如 1.0 → 0.05）；
2. **Boltzmann / softmax 探索**：按 Q 值的温度 softmax 采样；
3. **UCB**（bandit 经典）：选 $Q + c\sqrt{\ln t\,/\,N(a)}$，乐观面对不确定；

   **符号说明**：$a$ 是正在打分的动作，$Q$ 是该动作已有的平均收益估计，$t$ 是总尝试次数，$N(a)$ 是尝试动作 $a$ 的次数；$c$ 控制探索加分的强度，$\ln$ 是自然对数。

4. **动作空间噪声**：DDPG 用 OU 噪声（时序相关，适合物理控制）、高斯噪声；
5. **参数空间噪声（NoisyNet）**：给网络权重加可学习噪声，探索更一致；
6. **内在奖励 / 好奇心**：ICM（预测误差）、RND（随机网络蒸馏的预测误差）、count-based，用于稀疏奖励；
7. **Go-Explore**：记住并返回有前景状态，解决 Montezuma 类硬探索；
8. **可学习的探索**：SAC / PPO 的随机高斯策略，log_std 本身就是学出来的探索强度。

**一句话总结**：探索的本质是"给不确定性定价"，从手动 ε 到学出来的熵，越现代的方法越把探索交给优化。

## Q10 ★ 什么是"死亡三要素"（deadly triad）？

**标准答案**

Sutton & Barto 提出：**函数逼近 + bootstrapping + off-policy** 三者同时存在时，价值函数可能发散（即使线性逼近也会，如 Baird 反例）。

DQN 的两大技术本质就是在缓解它：target network 缓解 bootstrap 目标漂移；experience replay 打破样本相关性、近似 i.i.d.。

**加分项**：offline RL 之所以难，根本原因就是死亡三要素凑齐了——纯 off-policy 数据 + 神经网络逼近 + bootstrapping → 对 OOD 动作的外推误差被反复放大（见第七部分）。

**一句话总结**：三要素凑齐就可能发散，DQN 之后所有算法都在"拆散这个组合"。

## Q11 Model-based 和 Model-free 的区别？

**标准答案**

| | Model-based | Model-free |
|---|---|---|
| 学什么 | 学/已知环境模型 P、R | 直接学 value 或 policy |
| 代表 | Dyna、MCTS、Dreamer、MuZero | Q-learning、DQN、PPO、SAC |
| 样本效率 | 高（模型里"想象"数据） | 低 |
| 主要问题 | 模型误差累积（compounding error） | 数据饥渴 |

**一句话总结**：MB 是"先建个仿真器再在里面练"，MF 是"直接在真实交互里练"。

# 二、经典算法深度对比

## Q1 ★ Q-learning 和 SARSA 的区别（写出更新公式）？

**标准答案**

$$
\begin{aligned}
\text{SARSA (on-policy):}\quad
Q(s,a) &\gets Q(s,a) + \alpha\bigl[r + \gamma Q(s',a') - Q(s,a)\bigr], \\
\text{Q-learning (off-policy):}\quad
Q(s,a) &\gets Q(s,a) + \alpha\left[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\right].
\end{aligned}
$$

**符号说明**：$s,a$ 是当前状态和已经执行的动作，$s'$ 是这一步到达的状态，$r$ 是实际拿到的奖励。$Q(s,a)$ 是当前动作的估值，$Q(s',a')$ 是下一状态下动作 $a'$ 的估值。$\alpha$ 是学习率，$\gamma$ 是折扣因子，$\gets$ 表示写回新估值。SARSA 里的 $a'$ 是实际选的下一动作；Q-learning 里的 $\max_{a'}$ 是在下一状态比较所有可选动作，取最高估值。

关键区别：SARSA 的 bootstrap 目标用**实际执行的下一个动作** $a'$（包含探索动作的影响），Q-learning 用**贪心动作**（学的是最优贪心策略，与行为策略无关）。

**经典例子：Cliff Walking（悬崖行走）**。最优路径贴着悬崖走，但 ε-greedy 探索时有概率掉下去：
- Q-learning 学到贴崖最优路径（训练中经常掉下去，因为探索时被自己的 ε 害）；
- SARSA 学到绕开悬崖的安全路径（它把"我探索时会犯错"也学进了价值里）。

补充：Expected SARSA 对下一动作取期望而非采样，方差更小，可与贪心目标策略结合。

**一句话总结**：SARSA 把"自己会手滑"学进价值，Q-learning 假装自己永远最优地行动。

## Q2 ★★★ DQN 的两个核心技术是什么？为什么需要它们？

**标准答案**

DQN = Q-learning + 深度网络，损失函数：

$$
\begin{aligned}
L(\theta)
  &= \mathbb{E}_{(s,a,r,s')\sim\mathcal{D}}
     \bigl[(y - Q(s,a;\theta))^2\bigr], \\
y &= r + \gamma \max_{a'} Q(s',a';\theta^-).
\end{aligned}
$$

**符号说明**：

- $(s,a,r,s')$ 是一条经验：当前状态、已执行动作、实际奖励、下一状态。$\mathcal{D}$ 是经验回放池；$\sim$ 表示从中采样，$\mathbb{E}$ 表示对样本的损失求平均。
- $Q(s,a;\theta)$ 是在线网络对这条经验的预测，$\theta$ 是本次要更新的参数；$y$ 是该预测要靠近的 TD 目标。$L(\theta)$ 是预测与目标之间的均方误差。
- $\theta^-$ 是目标网络的参数，上标 $-$ 是记号，不是取负。$Q(s',a';\theta^-)$ 是目标网络给下一动作 $a'$ 的估值，$\max_{a'}$ 取这些估值中的最大值，$\gamma$ 控制它在 $y$ 中的权重。

**技术一：Experience Replay（经验回放）**
- 把交互样本存进 buffer，训练时随机采样；
- 作用 1：打破时序样本的强相关性，近似 i.i.d.，否则 SGD 学不动；
- 作用 2：样本复用，提高数据利用率。
- 升级：PER（优先经验回放），按 TD error 的绝对值采样，难样本多学；注意会引入偏差，要用 importance sampling 权重修正。

**技术二：Target Network（目标网络）**
- bootstrap 目标 $y$ 里的 $Q$ 用**冻结的旧参数** $\theta^-$ 计算，每隔 $C$ 步才从在线网络拷贝（或 soft update）；
- 作用：没有它，目标和预测用的是同一个网络，等于"追着自己的尾巴跑"，bootstrap 误差自激放大 → 震荡发散。

**高频追问：y 为什么不回传梯度？** 因为 y 是"监督目标"，对它求导会让网络靠移动目标来降 loss，形成正反馈发散；实现上必须 stop-gradient。

**加分项**：DQN 的 Q 值会系统性**过估计**——max 操作符对带噪声的估计取最大，期望上产生正向偏差（Jensen 不等式 / 最大值期望 ≥ 期望最大值），这正是 Double DQN 要解决的问题。

**一句话总结**：replay 治"样本相关"，target network 治"目标漂移"，两者都是在拆死亡三要素。

## Q3 ★ DQN 家族有哪些变体？各自解决什么问题？

**标准答案**

| 变体 | 解决的问题 | 核心做法 |
|---|---|---|
| Double DQN | Q 值过估计 | 动作用在线网络选（argmax），价值用目标网络评，解耦"选择"与"评估" |
| Dueling DQN | 很多状态下动作无所谓 | 网络分 $V(s)$ 和 $A(s,a)$ 两路再合并 $Q=V+A-\operatorname{mean}(A)$，V 学得更充分 |
| PER | 均匀采样低效 | 按 TD error 优先级采样 + IS 权重纠偏 |
| NoisyNet | ε-greedy 探索盲目 | 权重加可学习噪声，探索强度自适应 |
| Distributional（C51/QR-DQN） | 只学均值丢失分布信息 | 学回报的完整分布，风险敏感 |
| N-step return | 1-step bootstrap 传播慢 | 多步真实回报再 bootstrap，平衡偏差方差 |
| **Rainbow** | —— | 以上六者的合体，曾是 Atari 上的 SOTA |

**符号说明**：Dueling DQN 中，$s,a$ 是状态和动作；$V(s)$ 是状态价值分支的输出，$A(s,a)$ 是动作优势分支的输出，$\operatorname{mean}(A)$ 是固定状态 $s$ 后对各个动作的分支输出取平均，$Q$ 是合并后的动作价值估计。

**一句话总结**：DQN 家族各治一种病——过估计、学得慢、探索差、信息丢。

## Q4 ★★ 策略梯度定理？REINFORCE 算法？为什么加 baseline？

**标准答案**

目标：$J(\theta)=\mathbb{E}_{\tau\sim p_\theta}[R(\tau)]$。策略梯度定理（推导见第三部分）：

$$
\nabla_\theta J(\theta)
= \mathbb{E}_{\tau\sim\pi_\theta}\!\left[
  \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\,G_t
  \right].
$$

**符号说明**：

- $\theta$ 是策略参数，$\pi_\theta$ 是用它参数化的策略；$\tau$ 是一整条轨迹，$p_\theta$ 是该策略与环境交互所诱导的轨迹分布，$R(\tau)$ 是该轨迹的总回报。$J(\theta)$ 是平均轨迹回报，$\nabla_\theta J(\theta)$ 是它对策略参数的梯度。
- $t$ 是轨迹内的时间步，$s_t,a_t$ 是该步状态和动作；$\log\pi_\theta(a_t\mid s_t)$ 是这个动作在该状态下的对数概率（连续动作则为对数密度）。其梯度说明调整参数时，该动作的对数概率会怎样变。$G_t$ 是从第 $t$ 步起的回报，用来给该步梯度加权。
- $\sum_t$ 先累加同一条轨迹各步的贡献；$\mathbb{E}_{\tau\sim\pi_\theta}$ 再对当前策略采出的不同轨迹求平均。

REINFORCE：采样整条轨迹，用实际回报 $G_t$ 无偏估计上式，直接梯度上升。

问题：**方差极大**——整条轨迹的回报波动大，且所有动作共享同一回报的噪声。

解决：加 baseline $b(s)$：

$$
\nabla_\theta J(\theta)
= \mathbb{E}\!\left[\sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)
  \bigl(G_t - b(s_t)\bigr)\right].
$$

**符号说明**：$b(s_t)$ 是只依赖于状态的基线，$G_t-b(s_t)$ 衡量这次回报比基线高多少。$\theta$ 是策略参数，$s_t,a_t$ 是第 $t$ 步的状态和动作，$\nabla_\theta\log\pi_\theta(a_t\mid s_t)$ 是该动作的对数概率梯度；$\sum_t$ 对轨迹中的各步求和，$\mathbb{E}$ 对采到的轨迹求平均，$J$ 是要最大化的平均回报。

- 为什么无偏：$\mathbb{E}_{a\sim\pi}[\nabla\log\pi(a\mid s)\,b(s)]=b(s)\sum_a\nabla\pi(a\mid s)=b(s)\nabla 1=0$，baseline 与动作无关，期望为零，不改变梯度期望；
- 为什么降方差：减掉状态基准后，只奖励"超常发挥"的动作。
- 最优 baseline 是 $V(s)$，于是自然引出 Actor-Critic：$A=Q-V$。

**一句话总结**：REINFORCE 无偏方差大，减个 baseline 只降方差不引入偏差——这是策略梯度最重要的一招。

## Q5 ★ Actor-Critic 框架？GAE 是什么？

**标准答案**

Actor-Critic = 策略梯度 + 价值函数自举：
- **Actor**（策略 $\pi_\theta$）：沿 $\mathbb{E}[\nabla_\theta\log\pi_\theta(a\mid s)\,A(s,a)]$ 更新；
- **Critic**（价值 $V_w$ 或 $Q_w$）：用 TD 学价值，给 actor 提供低方差的优势估计（如 $\delta=r+\gamma V(s')-V(s)$ 当 $A$ 用）。

**符号说明**：$\theta$ 是 actor 参数，$w$ 是 critic 参数；$V_w$、$Q_w$ 分别表示用 critic 估计状态价值和动作价值的两种写法。$A(s,a)$ 是在状态 $s$ 做动作 $a$ 的优势，$\mathbb{E}$ 对训练用的状态和动作求平均。$\delta$ 是一步 TD 误差：$r$ 是即时奖励，$\gamma$ 是折扣因子，$V(s')$ 和 $V(s)$ 是下一状态与当前状态的估值。

A2C（同步）/ A3C（异步）：多环境并行采样，去相关、降方差；实践上同步版（A2C）配合 GPU 更常用。

**GAE（广义优势估计）**：在"偏差-方差"之间连续插值：

$$
A^{\mathrm{GAE}}(t) = \sum_{\ell\ge 0} (\gamma\lambda)^\ell\,\delta_{t+\ell}.
$$

**符号说明**：$A^{\mathrm{GAE}}(t)$ 是第 $t$ 步的优势估计，$\ell$ 是从这一刻往后的步数，$\delta_{t+\ell}$ 是对应那一步的 TD 误差。$\gamma$ 是奖励折扣因子，$\lambda$ 控制后续误差的权重；每多往后一步，权重再乘一次 $\gamma\lambda$。$\sum_{\ell\ge0}$ 从当前步开始累加，不跨入下一个回合。

- $\lambda=0$ → 单步 TD 优势：偏差大、方差小；
- $\lambda=1$ → 整条轨迹回报减 V：无偏、方差大；
- 常取 $\lambda=0.95$。

**一句话总结**：Critic 负责把"运气"从"实力"里剥掉，GAE 是剥多剥少的旋钮。

## Q6 ★ TRPO 的核心思想？

**标准答案**

动机：策略梯度对步长敏感——一步迈太大，新策略数据分布剧变，优势估计失效，性能崩盘且不可逆。

TRPO：每次更新**约束新旧策略的 KL 散度**：

$$
\max_\theta\ \mathbb{E}\!\left[\frac{\pi_\theta}{\pi_{\mathrm{old}}}\,A\right]
\quad \text{s.t.} \quad
\mathbb{E}\!\left[D_{\mathrm{KL}}(\pi_{\mathrm{old}}\Vert\pi_\theta)\right] \le \delta.
$$

**符号说明**：$\theta$ 是要优化的新策略参数，$\pi_\theta$ 和 $\pi_{\mathrm{old}}$ 是新、旧策略；两者之比是在同一状态下对同一个已采样动作比较概率（或密度）。$A$ 是旧策略下的优势；$\mathbb{E}$ 对旧策略采样求平均，KL 约束只对采到的状态求平均。$D_{\mathrm{KL}}$ 衡量新旧动作分布的差异；$\delta$ 是允许的平均 KL 上限，这里不是 TD 误差。$\text{s.t.}$ 表示「满足右侧约束」。

理论上近似保证性能单调提升（trust region）。实现：自然梯度方向 $F^{-1}g$（$g$ 是代理目标的梯度，$F$ 是 Fisher 信息阵，用共轭梯度法免显式求逆）+ line search 确保约束满足。

**一句话总结**：TRPO = 给每步更新划"信任域"，保证不迈出优势估计有效的范围；思想伟大，实现复杂 → 催生了 PPO。

## Q7 ★★★ PPO 的原理和实现细节（最高频深挖题）

**标准答案**

PPO 用一阶方法近似 TRPO 的信任域。概率比和 clipped 目标为：

$$
\begin{aligned}
\rho_t(\theta)
  &= \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\mathrm{old}}(a_t \mid s_t)}, \\
L^{\mathrm{CLIP}}(\theta)
  &= \mathbb{E}_t\!\left[\min\left(
    \rho_t(\theta) A_t,\;
    \operatorname{clip}\bigl(\rho_t(\theta),1-\varepsilon,1+\varepsilon\bigr) A_t
    \right)\right].
\end{aligned}
$$

**符号说明**：

- $t$ 是采样步，$s_t,a_t$ 是这一条样本的状态和动作。$\theta$ 是新策略参数，$\pi_\theta$ 和 $\pi_{\mathrm{old}}$ 分别是更新中的策略和采样时的策略。$\rho_t(\theta)$ 比较两种策略对该动作给出的概率（连续动作时为密度）。
- $A_t$ 是该步的优势估计，通常用 GAE 算。$\varepsilon$ 是裁剪区间的半宽，$\operatorname{clip}$ 把用于比较的那份概率比夹在 $1-\varepsilon$ 和 $1+\varepsilon$ 之间；$\min$ 在裁剪前、后的两个加权得分里取较小者。
- $\mathbb{E}_t$ 对采样批次中的时间步求平均；$L^{\mathrm{CLIP}}(\theta)$ 是 PPO 要最大化的策略代理目标。

裁剪参数 $\varepsilon$ 常取 $0.2$。

分两种情况看 clip 的作用：
- $A>0$（好动作）：$\rho$ 被限制在 $\rho\le 1+\varepsilon$，防止"过度鼓励"把策略推飞；
- $A<0$（坏动作）：$\rho$ 被限制在 $\rho\ge 1-\varepsilon$，防止"过度打压"。
取 min 保证目标是未 clip 目标的下界（悲观原则）。

**总损失**：$L=L^{\mathrm{CLIP}}-c_1 L_{\mathrm{value}}+c_2 H(\pi)$（critic 回归 + 熵奖励防过早收敛）。

**符号说明**：$L$ 是合并后的目标，$L^{\mathrm{CLIP}}$ 是上方的策略目标，$L_{\mathrm{value}}$ 是 critic 的价值回归损失，$H(\pi)$ 是策略 $\pi$ 的熵；$c_1$、$c_2$ 分别给价值损失、熵奖励加权。

**实现细节（真训过才知道，主动讲）**：
1. **Advantage 归一化**：每个 batch 内 A 减均值除标准差，稳定梯度尺度；
2. **Value loss clipping**：critic 也用 clip 防止价值函数一步跳太多；
3. **熵正则**：系数（如 0.01）防止 log_std 过早塌缩失去探索；
4. **学习率衰减** + **正交初始化**（策略头增益 0.01，价值头增益 1）；
5. **多 epoch minibatch**：同一批数据训几个 epoch（3~10），若 KL 超阈值（如 0.01~0.015 的 target KL）则 early stop；
6. **梯度裁剪**（global norm 0.5）；
7. **时间截断的 bootstrap**（见第四部分，经典 bug）。

**加分项**：Engstrom et al. 2020《Implementation Matters》研究表明，PPO 的稳定性很大程度来自这些代码级技巧而非算法本身——说这句非常加分。

**与 TRPO 对比**：PPO 无二阶优化、无共轭梯度，实现简单一个数量级，效果相当，所以成为工业界事实标准。

**一句话总结**：PPO = 用 clip 这种"穷人信任域"近似 TRPO，好用、稳、并行友好。

## Q8 ★ DDPG 与 TD3：确定性策略梯度及 TD3 的三个改进

**标准答案**

**DDPG**：连续动作下对动作求 max 不可行 → 用确定性策略 $a=\mu_\theta(s)$ 代替 argmax。critic 学 $Q(s,a)$，actor 沿确定性策略梯度上升（链式法则：让 $Q$ 更大方向调 $\mu$）：

$$
\nabla_\theta J = \mathbb{E}_s\!\left[
  \left.\nabla_a Q(s,a)\right\rvert_{a=\mu_\theta(s)}\,\nabla_\theta \mu_\theta(s)
  \right].
$$

**符号说明**：$s$ 是采样状态，$a$ 是动作，$\theta$ 是 actor 的参数，$\mu_\theta(s)$ 是 actor 给出的确定性动作，$Q(s,a)$ 是 critic 的估值。$\nabla_a Q$ 指出动作怎样改会提高估值，竖线下标表示在 actor 输出的动作处计算这个梯度。$\nabla_\theta\mu_\theta(s)$ 表示参数怎样影响动作；两项通过链式法则组合，对采样状态取平均（$\mathbb{E}_s$），得到回报目标 $J$ 对 actor 参数的梯度。

组件：off-policy + replay buffer + 双 target network + **soft update**（$\theta^-\gets\tau\theta+(1-\tau)\theta^-$，$\tau\approx 0.005$）；探索靠给动作加噪声（OU/高斯）。

**符号说明**：对 actor 和 critic 各自的软更新，$\theta$ 是对应的在线参数，$\theta^-$ 是目标参数；$\tau$ 是每次混入在线参数的比例，不是轨迹。$\gets$ 左侧是新目标参数，右侧的 $\theta^-$ 是旧目标参数。

**TD3（Twin Delayed DDPG）针对 DDPG 不稳的三个改进**：
1. **Clipped Double Q**：双 critic，目标值取 $\min(Q_1,Q_2)$，抑制 Q 过估计；

   **符号说明**：$Q_1,Q_2$ 是两个 critic 对同一个状态和动作的估值，$\min$ 取较小的一个。

2. **延迟更新（delayed policy update）**：actor 和 target 网络更新频率低于 critic（如每 2 步一次），等价值估准了再动策略；
3. **Target policy smoothing**：计算目标时给目标动作加截断噪声 $a'=\mu(s')+\operatorname{clip}(\varepsilon,-c,c)$，防止 actor 过拟合 Q 函数的尖锐峰值（对抗性钻空子）。

   **符号说明**：$s'$ 是下一状态，$\mu(s')$ 是目标 actor 给出的动作，$a'$ 是加噪后用于计算目标的动作。$\varepsilon$ 是本次采样的噪声，$c$ 是噪声幅度上限，$\operatorname{clip}$ 将噪声限制在 $[-c,c]$。

**一句话总结**：DDPG 用可微的 actor 代替 argmax；TD3 用"双 Q 取小、慢更新、目标加噪"三板斧把 DDPG 从难调教变成稳定可用。

## Q9 ★★ SAC 的核心思想？

**标准答案**

SAC（Soft Actor-Critic）= 最大熵 RL。目标函数在回报外再加**策略熵奖励**：

$$
J(\pi)=\mathbb{E}\!\left[\sum_t \bigl(r_t+\alpha H(\pi(\cdot\mid s_t))\bigr)\right].
$$

**符号说明**：$J(\pi)$ 是策略 $\pi$ 要最大化的回报加熵目标。$t$ 是时间步，$r_t$ 是这一步的奖励，$s_t$ 是对应状态；$H(\pi(\cdot\mid s_t))$ 是策略在该状态下对所有动作的分布的熵。$\alpha$ 是调节熵奖励权重的温度参数；$\sum_t$ 沿轨迹累加，$\mathbb{E}$ 对策略产生的轨迹求平均。

对应 soft Bellman 方程：$V(s)=\mathbb{E}_{a\sim\pi}[Q(s,a)-\alpha\log\pi(a\mid s)]$。

**符号说明**：$s,a$ 是状态、动作；$V(s)$ 和 $Q(s,a)$ 分别是考虑熵后的状态价值和动作价值。$\log\pi(a\mid s)$ 是在 $s$ 选择 $a$ 的对数概率或对数密度；$\mathbb{E}_{a\sim\pi}$ 表示在 $s$ 下按策略对动作求平均。

为什么加熵：
- 鼓励探索（不轻易坍缩成单动作）；
- 鲁棒性（学的是"所有高回报动作都给概率"，面对扰动更稳）；
- 最大熵目标下策略更新有平滑的理论性质。

关键组件：
1. **双 critic 取 min**（同 TD3，抑制过估计），target 网络 soft update；
2. **随机策略**：高斯分布 + tanh squash（动作限幅），采样用重参数化技巧（$a=\mu+\sigma\varepsilon$）保持可微，log-prob 要加 tanh 的 Jacobian 修正项；

   **符号说明**：$\mu$、$\sigma$ 是策略输出的高斯均值和标准差，$\varepsilon$ 是标准正态噪声，$a$ 是经过 tanh 限幅前采出的动作。

3. **自动温度调节**：$\alpha$ 不手调，作为对偶变量自动优化——约束平均熵不低于目标熵（取 $-\dim(A)$，连续动作维度的负值），熵低了就升 $\alpha$ 逼探索，熵够了就降 $\alpha$ 重回报。

**SAC vs PPO（高频对比）**：

| | SAC | PPO |
|---|---|---|
| 策略类型 | off-policy，随机 | on-policy，随机 |
| 样本效率 | 高（replay 复用） | 低（数据用一次） |
| 稳定性/调参难度 | 较稳 | 非常稳、鲁棒 |
| 适用 | 样本贵（实机）、中低维状态 | 大规模并行仿真、高吞吐 |

**一句话总结**：SAC = 最大熵 + 双 Q + 自动温度，把探索写进目标函数里，是连续控制样本效率的第一梯队。

## Q10 连续控制任务怎么选算法？（对比表）

**标准答案**

| | DDPG | TD3 | SAC | PPO |
|---|---|---|---|---|
| on/off-policy | off | off | off | on |
| 策略 | 确定性 | 确定性 | 随机 | 随机 |
| 样本效率 | 高 | 高 | 最高一档 | 低 |
| 稳定性 | 差（已少用） | 好 | 好 | 最好 |
| 典型场景 | 历史意义 | 连续控制基线 | 实机/样本贵 | 大规模并行仿真（Isaac Gym） |

腿式机器人 locomotion 领域默认 PPO（有海量并行仿真，稳定性优先）；实机直接在线学习或样本昂贵时考虑 SAC。

**一句话总结**：有并行仿真用 PPO 图稳，样本贵用 SAC 图省。

## Q11 ★ Value-based 和 Policy-based 方法对比？

**标准答案**

| | Value-based（DQN 系） | Policy-based（PG 系） |
|---|---|---|
| 动作空间 | 离散（要 argmax） | 离散/连续皆可 |
| 策略 | 隐式（对 Q 取贪心） | 显式参数化 |
| 收敛保证 | 函数逼近下无保证（死亡三要素） | 至少收敛到局部最优 |
| 方差 | 低 | 高（需 baseline/AC 缓解） |
| 能否学随机策略 | 不能（贪心确定） | 能（博弈、最大熵场景必需） |

**一句话总结**：value-based 间接但高效，policy-based 直接、能上连续动作、方差大要靠 critic 救。

# 三、手推公式高频题（白板题）

## 推导 1 ★★ 从回报定义推 Bellman 方程

$$
G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots = r_t + \gamma G_{t+1}.
$$

**符号说明**：$t$ 是当前时间步，$r_t,r_{t+1},r_{t+2}$ 是当前和后续各步的奖励，$\gamma$ 是每晚一步再乘一次的折扣因子。$G_t$ 是从当前步开始的折扣回报，$G_{t+1}$ 则从下一步开始计，不含当前的 $r_t$。

$$
\begin{aligned}
V^\pi(s)
  &= \mathbb{E}_\pi[G_t \mid s_t=s] \\
  &= \mathbb{E}_\pi[r_t + \gamma G_{t+1} \mid s_t=s] \\
  &= \sum_a \pi(a\mid s)\sum_{s',r} p(s',r\mid s,a)
     \bigl[r+\gamma\mathbb{E}_\pi[G_{t+1}\mid s_{t+1}=s']\bigr] \\
  &= \sum_a \pi(a\mid s)\sum_{s',r} p(s',r\mid s,a)
     \bigl[r+\gamma V^\pi(s')\bigr].
\end{aligned}
$$

**符号说明**：$\pi$ 是固定的策略，$V^\pi(s)$ 是从状态 $s$ 按它行动的期望回报；$G_t,G_{t+1}$ 是从当前、下一步起的折扣回报。$s_t,s_{t+1}$ 是轨迹中当前、下一步的状态；$s,s'$ 是对应的具体状态值。$r_t$ 是当前奖励，$r$ 是它的一种可能取值，$\gamma$ 是折扣因子。$\mathbb{E}_\pi$ 表示按策略与环境的随机性求平均，$\pi(a\mid s)$ 给当前动作 $a$ 加权，$p(s',r\mid s,a)$ 给各个可能的下一状态、奖励组合加权。

关键步骤：展开一项 → 对动作用 $\pi$ 取期望、对转移用 $p$ 取期望 → 识别出嵌套的 $V^\pi(s')$。

## 推导 2 ★★★ 策略梯度定理（必考）

轨迹目标和对数导数技巧（$\nabla p=p\,\nabla\log p$）：

$$
\begin{aligned}
J(\theta)
  &= \mathbb{E}_{\tau\sim p_\theta}[R(\tau)]
   = \int p_\theta(\tau) R(\tau)\,\mathrm{d}\tau, \\
\nabla_\theta J(\theta)
  &= \int \nabla_\theta p_\theta(\tau) R(\tau)\,\mathrm{d}\tau \\
  &= \int p_\theta(\tau)\,\nabla_\theta\log p_\theta(\tau)\,R(\tau)\,\mathrm{d}\tau \\
  &= \mathbb{E}_{\tau\sim p_\theta}\bigl[\nabla_\theta\log p_\theta(\tau)\,R(\tau)\bigr].
\end{aligned}
$$

**符号说明**：$\theta$ 是策略参数，$\tau$ 是一条轨迹，$p_\theta(\tau)$ 是该轨迹的概率密度，$R(\tau)$ 是这条轨迹的总回报；$J(\theta)$ 是这些回报的期望。$\nabla_\theta$ 表示对参数求梯度，$\log$ 是自然对数；$\int \cdots\,\mathrm{d}\tau$ 对轨迹积分，$\mathbb{E}_{\tau\sim p_\theta}$ 表示按轨迹分布取期望。上面技巧里的 $p$ 指被求梯度的概率密度。

展开轨迹概率，再取对数：

$$
\begin{aligned}
p_\theta(\tau)
  &= p(s_0)\prod_t \bigl[\pi_\theta(a_t\mid s_t)\,p(s_{t+1}\mid s_t,a_t)\bigr], \\
\log p_\theta(\tau)
  &= \log p(s_0)+\sum_t \log \pi_\theta(a_t\mid s_t)
     +\sum_t \log p(s_{t+1}\mid s_t,a_t).
\end{aligned}
$$

**符号说明**：$\tau$ 是由起始状态和逐步状态、动作组成的轨迹；$\theta$ 是策略参数，$p_\theta(\tau)$ 是整条轨迹的概率或密度。$p(s_0)$ 给出起始状态 $s_0$ 的概率或密度；$t$ 是轨迹内的时间步，$s_t,a_t$ 是当前状态、动作，$s_{t+1}$ 是下一状态。$\pi_\theta(a_t\mid s_t)$ 由策略给出，$p(s_{t+1}\mid s_t,a_t)$ 由环境给出。$\prod_t$ 把这些因子逐步相乘，取对数后变为 $\sum_t$，也就是逐步相加。

对 $\theta$ 求梯度后，初始状态分布和转移动力学项全部消失（与 $\theta$ 无关）：

$$
\begin{aligned}
\nabla_\theta J(\theta)
  &= \mathbb{E}\!\left[\sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t)\,R(\tau)\right] \\
  &= \mathbb{E}\!\left[\sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t)\,G_t\right].
\end{aligned}
$$

**符号说明**：$\nabla_\theta J(\theta)$ 是期望回报对策略参数 $\theta$ 的梯度；$t$ 是时间步，$s_t,a_t$ 是当时的状态和动作，$\nabla_\theta\log\pi_\theta(a_t\mid s_t)$ 是该动作的对数概率梯度。$R(\tau)$ 对整个轨迹 $\tau$ 计回报，$G_t$ 只计从第 $t$ 步开始的回报。$\sum_t$ 先对轨迹各步求和，$\mathbb{E}$ 再对轨迹求平均。

**考官最想听的两点**：
1. 动力学项被 log-trick 消掉了 → **这就是为什么策略梯度是 model-free 的**；
2. $G_t$ 而不是 $R(\tau)$：$t$ 时刻的动作只能影响从 $t$ 起的奖励（causality / reward-to-go），进一步降方差。

## 推导 3 ★★ baseline 为什么不引入偏差

$$
\begin{aligned}
\mathbb{E}_{a\sim\pi_\theta}\bigl[\nabla_\theta\log\pi_\theta(a\mid s)\,b(s)\bigr]
  &= b(s)\sum_a \nabla_\theta\pi_\theta(a\mid s) \\
  &= b(s)\,\nabla_\theta\sum_a\pi_\theta(a\mid s) \\
  &= b(s)\,\nabla_\theta 1 = 0.
\end{aligned}
$$

**符号说明**：$s$ 是固定状态，$a$ 是按策略 $\pi_\theta$ 抽出的动作；$\theta$ 是策略参数，$\nabla_\theta$ 表示对它求梯度。$\mathbb{E}_{a\sim\pi_\theta}$ 按 $\pi_\theta(a\mid s)$ 对各动作求平均，$\sum_a$ 枚举全部动作，动作概率之和是 $1$。$b(s)$ 只依赖状态、不依赖动作，因此可以提出期望。

结论：任何不依赖动作的 baseline 都不改变梯度期望，只改变方差。

## 推导 4 ★ 重要性采样（IS）与 PPO 的 ratio 由来

off-policy 评估：想用行为策略 $\mu$ 采的样本估计目标策略 $\pi$ 下的期望：

$$
\begin{aligned}
\mathbb{E}_{a\sim\pi}[f(a)]
  &= \int \pi(a) f(a)\,\mathrm{d}a \\
  &= \int \mu(a)\,\frac{\pi(a)}{\mu(a)}\,f(a)\,\mathrm{d}a \\
  &= \mathbb{E}_{a\sim\mu}[\rho(a) f(a)].
\end{aligned}
$$

**符号说明**：$a$ 是动作，$f(a)$ 是要取平均的量；$\pi(a)$ 和 $\mu(a)$ 分别是目标策略和行为策略给该动作的密度。$\rho(a)=\pi(a)/\mu(a)$ 是该样本的重要性权重。$\mathbb{E}_{a\sim\pi}$ 是想估计的目标策略期望，$\mathbb{E}_{a\sim\mu}$ 是按实际采样策略求平均；$\mathrm{d}a$ 表示对连续动作积分。要使用这个比值，目标策略可能选的动作也必须在行为策略的覆盖范围内。

PPO：数据来自旧策略 $\pi_{\mathrm{old}}$，目标是改进新策略 $\pi_\theta$，于是优势加权的目标变成 $\mathbb{E}[\rho_t(\theta)A_t]$，$\rho=\pi_\theta/\pi_{\mathrm{old}}$。因为 IS 在分布差异大时方差爆炸，所以加 clip 把 $\rho$ 钉在 $1\pm\varepsilon$ 内——**clip 本质是对 IS 方差的暴力截断**。

**符号说明**：PPO 中的 $\rho_t(\theta)$ 是新旧策略对第 $t$ 步同一动作的概率比，$A_t$ 是该步的优势估计，$\theta$ 是新策略的参数；$\varepsilon$ 控制裁剪区间的宽度，$\mathbb{E}$ 对旧策略采出的样本求平均。

## 推导 5 ★ 手算小 MDP（现场算题，提前演练）

常考形式：给一个 2~3 状态的小 MDP（转移矩阵、奖励、γ），让你：
1. 手算一步值迭代：$V_{k+1}(s)=\max_a\sum_{s',r}p(s',r\mid s,a)[r+\gamma V_k(s')]$；

   **符号说明**：$k$ 是迭代轮数，$V_k$ 是这一轮已有的价值估计，$V_{k+1}$ 是更新后的价值。$s,a$ 是当前状态、候选动作，$s',r$ 是可能的下一状态和奖励；由 $p(s',r\mid s,a)$ 加权求平均，再用 $\max_a$ 选得分最高的动作。$\gamma$ 折扣的是上一轮对下一状态的估值。

2. 或手算一步 Q-learning / SARSA 更新（给定 α、γ、一条转移样本）；
3. 或写出 Bellman 方程组并解线性方程（状态少时可解析解）。

**演练示例**：状态 A 有两动作，$a_1$ 以概率 $1.0$ 转移到 B，拿 $r=1$；$a_2$ 以概率 $1.0$ 停在 A，拿 $r=0.5$；状态 B 是终点。取 $\gamma=0.9$，求 $V^*(A)$。
- $V^*(A)=\max\bigl(1+0.9\cdot 0,\,0.5+0.9 V^*(A)\bigr)$。若选 $a_2$，则 $V=0.5+0.9V$，解得 $V=5$；比较 $\max(1,5)=5$，所以 $V^*(A)=5$，选 $a_2$。

  **符号说明**：$V^*(A)$ 是从状态 A 出发的最优价值，$V$ 是一直选 $a_2$ 时的价值。$a_1$ 拿 $1$ 分后到终点，后续价值为 $0$；$a_2$ 拿 $0.5$ 分后回到 A，后续价值打 $0.9$ 折。

- 教训：γ 大时"缓慢永续"可能优于"立刻终结"，这正是折扣因子影响行为的直观例子。

## 推导 6 ★ SAC 的 soft Bellman 方程（选考）

最大熵目标下定义 soft Q：

$$
\begin{aligned}
Q_{\mathrm{soft}}(s,a)
  &= r+\gamma\mathbb{E}_{s'}[V_{\mathrm{soft}}(s')], \\
V_{\mathrm{soft}}(s)
  &= \mathbb{E}_{a\sim\pi}[Q_{\mathrm{soft}}(s,a)-\alpha\log\pi(a\mid s)].
\end{aligned}
$$

**符号说明**：$s,a$ 是当前状态和动作，$r$ 是即时奖励，$s'$ 是下一状态，$\gamma$ 是折扣因子。$Q_{\mathrm{soft}}$ 和 $V_{\mathrm{soft}}$ 分别是计入熵奖励的动作价值和状态价值。$\mathbb{E}_{s'}$ 对环境给出的下一状态求平均，$\mathbb{E}_{a\sim\pi}$ 对策略 $\pi$ 在 $s$ 选的动作求平均。$\log\pi(a\mid s)$ 是动作的对数概率或对数密度，$\alpha$ 是熵项的温度系数。

期望里的 $-\alpha\log\pi(a\mid s)$ 是熵奖励项。

soft 策略迭代：策略评估用上面 soft Bellman 算子迭代（可证收敛），策略改进把 $\pi$ 投影到 $\exp(Q_{\mathrm{soft}}/\alpha)$ 方向（softmax 形式的最优解）。SAC 是其函数逼近版本。

# 四、深度 RL 工程实践（体现真训过模型）

## Q1 ★★ 训练不收敛 / 不稳定，你怎么排查？（开放题，按清单答）

**标准答案（分层排查法）**

1. **先看曲线，定位症状**：
   - reward 完全不动 → 探索不够 / 奖励太稀疏 / 学习率过低 / 网络没学到东西（查 explained variance）；
   - reward 涨了又崩 → 步长过大 / KL 失控 / target 网络问题 / 死亡三要素；
   - 熵（entropy）过早塌缩 → 熵系数太小，策略失去探索，陷入局部最优。
2. **数值健康检查**：
   - 观测是否归一化？（obs 量纲差几个数量级会直接毁掉训练）；
   - reward 量级是否合适？（clip 或 normalize；reward 太大导致 value loss 爆炸）；
   - 梯度范数？（grad clip 0.5）；价值损失占比？
3. **实现 bug 排查（最高频的实际原因）**：
   - **done 处理错误**：超时截断（time-limit）和真正终止（如摔倒）必须区分！截断时 bootstrap 目标仍要加 $\gamma V(s')$，终止时才不加。搞反 = 价值系统性失真，这是最经典的 bug；
     这里 $\gamma$ 是折扣因子，$V(s')$ 是截断前最后到达的状态的估值，不是重置后初始状态的估值。
   - 动作没 clip 到合法范围 / tanh 饱和；
   - advantage 忘了 detach、log_prob 图断了；
   - reward 忘乘 dt（积分步长），换控制频率后奖励尺度全变；
4. **算法层面**：换随机种子确认不是 seed 方差；减小 lr；增大 batch（on-policy 需要大 batch 降方差）；调 GAE λ。

**一句话总结**：先读曲线定性、再查数值健康、最后怀疑实现 bug，其中 done/bootstrap 处理和归一化是重灾区。

## Q2 ★★ Reward shaping 有什么原则？稀疏奖励怎么办？

**标准答案**

**原则：potential-based shaping（Ng et al. 1999）**：

$$
F(s,a,s') = \gamma\Phi(s')-\Phi(s).
$$

**符号说明**：$s,a$ 是转移前的状态和动作，$s'$ 是下一状态，$F(s,a,s')$ 是加到原奖励上的塑形项。$\Phi$ 是人为定义的状态势函数，$\Phi(s)$ 和 $\Phi(s')$ 分别是转移前后的势值；$\gamma$ 使用和原任务相同的折扣因子。

只有这种形式**保证不改变最优策略**（可证）。随意加 shaping 项极易导致 **reward hacking**：智能体找到刷分项而非完成任务。
- 经典翻车例子：给机器人"姿态稳定"奖励，它学会原地站着不动（不摔但也不走路）；给"抬腿"奖励，它原地踏步。

**稀疏奖励的对策**：
1. **HER（事后经验回放）**：goal-conditioned 任务中，把"实际到达的状态"当作目标重新存进 buffer，把失败轨迹变成"成功的另一种目标"的轨迹——机器人操作任务标配；
2. **内在好奇心**：ICM（前向模型预测误差）/ RND，奖励"没见过的东西"；
3. **课程学习（curriculum）**：从简单任务逐步加难度（legged_gym 的地形等级就是典型）；
4. **模仿学习冷启动**：先用专家数据 BC，再 RL 微调，绕过探索问题；
5. reward 分解 + 分层 RL。

**一句话总结**：shaping 要么用势函数保证策略不变，要么就接受"智能体一定比你更会钻奖励的空子"。

## Q3 ★★（机器人方向必问）大规模并行仿真为什么和 PPO 是绝配？

**标准答案**（结合 Isaac Gym / legged_gym 实操）

Isaac Gym 把**物理仿真和渲染都放在 GPU 上**，观测、奖励通过 GPU 上的 tensor 直接读写，几千个环境（如 4096 个）并行 rollout，全程没有 CPU↔GPU 的数据搬运（这是它比 MuJoCo + 多进程快几个数量级的原因）。

为什么配 PPO：
- PPO 是 on-policy，**每次迭代都要全新数据**——这本来是它的缺点（样本效率低）；
- 但并行仿真恰好能源源不断地廉价生产海量 on-policy 样本：一次 rollout = 4096 envs × N 步，直接喂给 PPO 的多 epoch 更新；
- 于是"用 wall-clock 时间换样本效率"，on-policy 的缺点被并行度掩盖，优点（稳定、鲁棒）保留。

工程直觉：
- batch = num_envs × num_steps（如 4096 × 16/24），batch 大了可以放大学习率；

  **符号说明**：`num_envs` 是并行环境数，`num_steps`（上面的 `N`）是每个环境在本轮采集的步数，`batch` 是这一轮产生的总样本数，不是一次梯度更新的小批量大小。

- obs_buf 的第一维就是环境数（4096），所有计算是批量向量化的，无 Python 层 for 循环；
- decimation（如 4）：仿真 200Hz、控制 50Hz，一次控制动作重复执行 4 个仿真步，既贴近真实控制器频率又省计算。

**一句话总结**：PPO 的命门是"数据用完就扔"，GPU 并行仿真的强项是"数据无限量供应"，两者互补。

## Q4 ★ 关键超参数的影响直觉（表）

**标准答案**

| 超参 | 典型值 | 调大的影响 | 调小的影响 |
|---|---|---|---|
| $\gamma$ | 0.99 / 0.995 | 看得远、方差大、收敛慢 | 短视、收敛快 |
| GAE $\lambda$ | 0.95 | 优势偏差小方差大 | 反之 |
| lr | 3e-4（PPO） | 学得快但可能崩 | 慢、可能卡住 |
| PPO clip $\varepsilon$ | 0.2 | 步长大、不稳 | 保守、学不动 |
| entropy coef | 0.01 | 探索多、收敛慢 | 熵塌缩、局部最优 |
| batch size | 大（数万） | 梯度稳、吞吐要求高 | 梯度噪声大 |
| epoch 数 | 3~10 | 数据利用高、KL 易超 | 浪费数据 |

**一句话总结**：调参顺序先定 γ 和奖励（任务定义层），再定 lr/batch（优化层），最后微调 clip/entropy（稳定层）。

## Q5 ★ 怎么判断训练收敛了？（结合真实日志指标）

**标准答案**

1. **主指标曲线**：mean reward 进入平台期且波动收窄；腿式机器人看 **mean_episode_length 是否拉满**（episode 上限 1000 步 = 20s，拉满 = 全程不摔倒 ≈ 任务收敛）；
2. **critic 健康度**：explained variance 应趋近 1（接近 0 说明价值函数没学到，actor 在听噪声）；
3. **KL 散度**：PPO 的 approx_KL 应稳定在 target KL 附近（0.01 量级），持续飙升 = 步长过大；
4. **熵曲线**：缓慢下降到合理水平是好的；骤降到 0 = 探索崩溃；
5. **多种子**：RL 方差大，结论要跨 3~5 个 seed 验证。

**一句话总结**：别看单条 reward 曲线就下结论——reward、episode length、KL、熵、explained variance 五件套一起看。

# 五、自动驾驶中的 RL（岗位相关，重点准备）

## Q1 ★★★ 为什么量产自动驾驶很少直接用端到端 RL？

**标准答案（四点结构性原因）**

1. **安全约束**：RL 的学习过程依赖探索（试错），而真实道路上"试错"的代价是事故。探索在物理世界不可接受。
2. **长尾分布**：驾驶的安全关键场景（cut-in、鬼探头、无保护左转博弈）在真实数据中占比极低，随机探索几乎采不到，采到了也不够密集。
3. **奖励难以定义**："好驾驶"是安全、效率、舒适、合规、类人的多目标权衡，写成标量 reward 会丢失大量信息，且必然被 hack。
4. **可验证性要求**：车规体系（ISO 26262 / SOTIF）要求行为可解释、可回归验证，端到端学习策略是黑盒，无法通过传统功能安全认证。

**因此业界主流范式**：
- **模仿学习为骨架**（从人类司机日志学先验，解决"从零探索"问题）；
- **RL 做后训练 / 局部优化**（在闭环仿真中优化通过率、效率等长期指标）；
- 或 **RL 只用于决策层**（离散的高层决策），底层控制交给确定性、可验证的方法；
- 输出永远过一层**规则化的安全校验**（碰撞检查、可达集），安全兜底与学习解耦。

**一句话总结**：不是 RL 不行，而是"探索要钱、黑盒要命"——所以 IL 打骨架、RL 做优化、规则做兜底。

## Q2 ★★ RL 在自动驾驶里到底用在哪？

**标准答案**

1. **行为决策（最成熟）**：变道、汇入、无保护左转、让行/抢行博弈。离散动作空间 → DQN 系 / PPO；多车博弈 → MCTS、多智能体 RL。
2. **规划策略的后训练微调**：先用 IL 学人类司机，再用 RL 在闭环仿真里优化通过率/效率/舒适性等长时序指标（与 LLM 的"SFT + RLHF"同构）。
3. **离线 RL 挖掘路测日志**：海量历史日志是 off-policy 数据金矿，离线 RL 试图从中提取超越人类平均水平的策略（难点见第七部分）。
4. **对抗场景生成**：用 RL 训练"刁难自车"的背景车智能体，自动发现 planning 的漏洞，比手工构造场景高效。
5. **world model / 可微仿真**：学一个数据驱动的环境模型（如 Wayve GAIA-1 这类生成式世界模型），让 RL 在"想象的闭环"里训练。

可引用的公开工作（体现阅读量）：ChauffeurNet（IL + 扰动增广治 covariate shift）、UniAD（CVPR 2023 最佳论文，规划导向的端到端）、GAIA-1（生成式世界模型）。

**一句话总结**：RL 在自动驾驶的主战场是"决策与微调"，不是"端到端打方向盘"。

## Q3 ★★ 如果让你设计自动驾驶 RL 的状态 / 动作 / 奖励，你怎么设计？

**标准答案（分层设计，体现工程思维）**

**状态**：
- 矢量化表示（主流）：车道线/车道中心线 polyline、红绿灯状态、他车历史轨迹（位置/速度/朝向/意图）、自车状态（速度、加速度、朝向）；
- 或 BEV 语义栅格 / occupancy grid（更通用但维度高）；
- 注意马尔可夫性：他车"历史轨迹"必须包含，否则他车意图不可观测（POMDP 问题）。

**动作（分层是标准做法）**：
- 高层（RL 负责）：离散决策——车道保持 / 左变道 / 右变道 / 减速让行 / 加速通过；
- 底层（确定性方法负责）：MPC / 采样优化生成平滑轨迹，横纵向控制；
- 端到端方案：直接输出加速度和前轮转角（连续动作 → PPO/SAC），但量产很少用。

**奖励（多目标加权 + 硬约束分离）**：
- 安全：碰撞（大惩罚并终止）、TTC 过小、冲出可行驶区域；
- 效率：纵向速度跟踪、通行时间、不合理停车；
- 舒适：jerk（加速度变化率）、横向加速度、急刹频率；
- 合规：超速、闯红灯、压实线；
- 类人：与人类司机日志的行为偏差（这一项同时充当正则，防 RL 学出"效率高但吓人"的驾驶风格）。

**权重怎么调**：安全类尽量做成**硬约束**（safety shield / CMDP，见 Q4），不进奖励；soft 项逐个加，每加一项自问"智能体会怎么 hack 它"；用闭环指标而非 reward 本身验收。

**一句话总结**：状态要马尔可夫、动作要分层、奖励要"安全硬约束 + 多目标软加权"。

## Q4 ★★ 用 RL 做驾驶决策，安全怎么保证？

**标准答案（三层防线）**

1. **训练期**：在闭环仿真里放开探索；危险动作由 **safety shield** 拦截替换（规则 fallback、控制障碍函数 CBF、前向可达集检验）。智能体提建议，安全层有一票否决权。
   - **主动串联你的经验**：这和量产架构里"规划输出必须过碰撞检查模块"是同一思想——学习模块永远在安全护栏内活动（你做过的 ncc 碰撞检查就是这个"护栏"的工程形态）。
2. **算法期**：把安全写成约束而非奖励——**约束 MDP（CMDP）**：最大化回报 s.t. 碰撞相关代价的期望 ≤ 阈值；用 Lagrangian 对偶（如 RCPO）自动调罚权重；safe exploration 方法限制策略只在安全集合内更新。
3. **验证期**：大规模闭环仿真回归（百万公里级）、对抗/边缘场景库、SOTIF 场景覆盖分析。开环 log replay 不能验证策略（见 Q6）。

**一句话总结**：安全不靠奖励祈求，靠"护栏（shield）+ 约束（CMDP）+ 验证（闭环回归）"三层体系。

## Q5 ★★ 模仿学习 + RL 微调的范式为什么流行？

**标准答案**

- **纯 RL 从零学**：探索效率太低，且早期行为危险、不类人；
- **纯模仿学习（BC）**：简单稳定，但有两个天花板——①性能上限被人类数据锁死；②**协变量偏移（covariate shift）**：训练分布是专家轨迹，测试时策略自己走，一步偏、步步偏，进入训练从未见过的状态后行为不可控。DAgger（在线让专家标注策略访问到的状态）是经典解法，但需要可查询的专家；
- **IL + RL 微调**：BC 给先验（解决探索与冷启动），RL 在闭环仿真里基于 BC 初始化继续优化长期指标（通过率、效率），并用 **KL 正则 / BC 损失锚定**防止策略跑偏出人类行为流形。

**加分项（串联展示知识面）**：这和 LLM 的"SFT + RLHF（带 KL 惩罚）"在数学上是同一个范式——先克隆先验，再在先验附近用 RL 优化对齐目标。机器人领域 VLA + RL 后训练（如 GRPO 类方法）也是同一思想。

**一句话总结**：IL 解决"从哪开始"，RL 解决"比人更好"，KL 正则负责"别跑偏"。

## Q6 ★ 自动驾驶 RL 怎么评估？开环指标够吗？

**标准答案**

- **开环（log replay）**：拿历史日志回放，比较预测轨迹与真实轨迹（ADE/FDE）。**严重缺陷**：环境不会对你的动作做反应——你"预测"要撞车，日志里的后车不会因此刹车；也无法评估任何反事实决策。开环指标好 ≠ 闭环安全。
- **闭环仿真（必须）**：背景车/行人由反应式模型驱动，自车策略真的在"开车"。核心指标：
  - 安全：碰撞率、接管率、最小 TTC 分布、违规率；
  - 效率：行程时间、通行率（无保护左转成功率等）；
  - 舒适：jerk、急刹率；
  - 统计显著性：场景采样方差大，需大量场景 + 分层报告。
- 进阶：用 RL/对抗方法自动生成高危场景库，专打策略弱点。

**一句话总结**：开环指标看"像不像人"，闭环指标看"安不安全"，自动驾驶只认后者。

# 六、机器人中的 RL（结合你的 legged_gym / openpi 实战）

## Q1 ★★★ sim2real gap 的来源有哪些？怎么弥合？

**标准答案**

**gap 来源（四大类）**：
1. **动力学建模误差**：摩擦系数、接触模型（软接触/形变）、电机特性（齿隙、温漂、扭矩-转速曲线非线性）、连杆质量/惯量标定误差；
2. **延迟**：传感器延迟、通讯延迟、执行器响应延迟（仿真里动作瞬时生效，真实系统有几十 ms 滞后）；
3. **传感噪声与漂移**：IMU 偏置、关节编码器噪声、深度相机在边缘/反光处的失真；
4. **未建模效应**：线缆拖拽、地面材质变化、制造公差。

**弥合手段**：
1. **Domain Randomization（主力手段）**：训练时随机化物理参数（摩擦、质量、电机强度、质心偏移）、加外力扰动（随机推搡）、加观测噪声、加动作延迟——策略见的"世界族"足够宽，真实世界只是其中一个样本，于是学到鲁棒策略；
2. **系统辨识（SysID）**：用实机数据反标仿真参数，把 gap 从源头缩小（与 DR 互补：SysID 缩均值偏差，DR 覆盖残余方差）；
3. **Actuator Network**：ANYmal 经典做法——用实机数据学一个电机网络，替代理想 PD 模型，把真实执行器的非线性搬进仿真（Hwangbo et al. 2019）；
4. **在线适应（RMA 类）**：策略额外输入一个从近期历史编码出的"环境参数 embedding"，部署时在线适应真实动力学；
5. **real2sim2real / 数字孪生**：用实机数据校准仿真再训练。

**一句话总结**：gap 来自"仿真对物理的简化"，对策 = 标定缩均值 + 随机化盖方差 + 学习补非线性。

## Q2 ★★★ 腿式机器人 locomotion 的标准训练 pipeline？（必能完整复述）

**标准答案（以 legged_gym / ANYmal 为例，就是你自己跑通的流程）**

1. **仿真**：Isaac Gym，4096 个机器人并行，物理在 GPU 上跑，观测/奖励 GPU 直读；
2. **观测（本体感受，约 48 维）**：基座角速度、重力在机体系投影、速度指令、12 关节位置、12 关节速度、上一帧动作；（训练期 critic / 特权版本另有线速度、地形高度扫描、接触力等）
3. **动作**：12 维关节**位置目标**（相对 default pose 的偏移），经 PD 控制器转成力矩；
   - 追问"为什么不直接输出力矩"：位置目标 + PD 天然平滑、限幅明确、对 sim2real 友好（电机响应的非线性被 PD 吸收一部分），直接力矩控制难训且伤电机；
4. **奖励**：任务项（线速度跟踪、角速度跟踪）+ 正则项（力矩惩罚、关节加速度、动作变化率 action rate、姿态惩罚、足底滑移、碰撞、能耗）共十几项加权和；
5. **课程学习**：地形难度分等级（平地→台阶→陡坡），跟踪误差达标自动升级，不达标降级；速度指令范围也逐步扩大；
6. **算法**：PPO（rsl_rl 实现），on-policy，每次迭代全新数据；
7. **收敛判据**：mean_episode_length 拉满 1000 步（= 20s 不摔倒）、速度跟踪误差进入平台；
8. **Domain randomization**：摩擦、负载质量、电机强度、随机推力，为 sim2real 准备。

**一句话总结**：GPU 并行仿真 + PPO + 速度跟踪奖励 + 地形课程 + 域随机化，就是腿式 locomotion 的"五件套"。

## Q3 ★★ locomotion 的奖励函数怎么设计？调奖励时踩过什么坑？

**标准答案**

奖励分两类：
- **任务奖励（想要什么）**：$\exp\bigl(-k\lVert v_{\mathrm{cmd}}-v\rVert^2\bigr)$ 形式的速度跟踪（指数形式让奖励平滑有界、梯度随误差自适应）；

  **符号说明**：$v_{\mathrm{cmd}}$ 是指令速度，$v$ 是实际速度；$\lVert v_{\mathrm{cmd}}-v\rVert^2$ 是速度误差的平方范数。$k$ 是大于零的误差敏感系数，$\exp$ 是指数函数；$k$ 越大，同样的误差使奖励下降得越多。

- **正则/风格奖励（不想要什么）**：力矩、关节加速度、action rate（相邻步动作差）、非期望接触（膝盖/基座撞地）、足底滑移、姿态偏离。正则项决定"走得像不像样"，任务项决定"走不走得到"。

**经典坑（面试讲这个极加分）**：
- 正则项权重过低 → 机器人动作高频抖动、电机过热（仿真里无所谓，实机会烧）；
- 任务项权重相对姿态项不足 → 原地站着不动拿姿态奖励（reward hacking）；
- 指令为零时没有特殊处理 → 策略学出"原地小碎步"刷跟踪奖励；
- 各奖励项要乘 dt，否则改控制频率后奖励尺度全变。

**一句话总结**：任务奖励定义"目标"，正则奖励定义"姿态"，调奖励本质是和中学生作弊心理做斗争。

## Q4 ★★ 什么是 teacher-student / 特权信息学习（asymmetric actor-critic）？

**标准答案**

核心观察：**critic（或 teacher）只在训练时用，部署时扔掉**——所以训练期可以喂它在真实机器人上拿不到的特权信息（精确线速度、地形高度图、接触状态、未来扰动）。

两种用法：
1. **Asymmetric Actor-Critic**：actor 看机载传感，critic 看特权信息 → critic 估计更准 → actor 梯度质量更高；
2. **Teacher-Student 蒸馏**：teacher 用特权信息（如全地形高度 scan）训出强策略，student 只用部署可用的传感（深度相机重建的高度）模仿 teacher → 部署无障碍。ETH 的 ANYmal 视觉 locomotion 就是这个范式。

**一句话总结**：训练期开天眼、部署时只用机载传感——特权信息是仿真训练白送的福利，不用白不用。

## Q5 ★★ 操作（manipulation）领域，RL 和 VLA 各自什么位置？（结合 openpi）

**标准答案**

- locomotion 任务：状态低维明确、物理仿真保真度高 → **RL（PPO）是绝对主场**；
- manipulation 任务：观测是高维视觉、任务语义多样（开抽屉/叠衣服/分拣）、长时序 → 纯 RL 从零训样本效率不可接受；
- 当前主流：**VLA 大模型（如 π0/π0.5）靠大规模模仿预训练获得泛化能力**，把互联网视觉-语言先验和机器人示教数据蒸进一个策略；
- **RL 的位置变成"后训练对齐"**：在 VLA 基础上用 RL 微调具体任务的成功率（类似 LLM 的 RLHF 阶段），GRPO 类方法（免 critic、组内相对优势）因为在单机上好实现而流行；
- 另一位置：**离线/在线 RL 做小规模专项提升**（某个具体工位的成功率从 80% → 99%）。

**一句话总结**：locomotion 是 RL 的主场，manipulation 是 IL/VLA 的主场，RL 在其中做"最后一公里"的成功率对齐。

## Q6 ★ 为什么 locomotion 普遍用 PPO 而不是 SAC？

**标准答案**

1. 有 Isaac Gym 级别的并行仿真时，PPO 的"样本效率低"缺点被无限数据掩盖；
2. PPO 对超参极其鲁棒、无 replay buffer 的内存和实现负担、无需维护 target 网络；
3. SAC 的 replay buffer 存高维观测（尤其视觉）在 4096 环境吞吐下内存爆炸；
4. 实机直接在线学习（样本昂贵、不能并行）才是 SAC 的主场。

**一句话总结**：选 PPO 不是因为它样本效率高，而是因为当样本免费时，稳定性才是最贵的。

# 七、前沿方向（拉开区分度的部分）

## Q1 ★★ Offline RL 为什么这么难？代表方法？

**标准答案**

核心困难：**外推误差（extrapolation error）**。离线数据的动作分布是固定的，而 Q 学习的目标 $r+\gamma\max_{a'}Q(s',a')$ 会去查询数据里没出现过的动作；函数逼近对 OOD 动作的估计是无约束的外推，一旦高估，bootstrapping 会把误差逐轮放大 → Q 值发散。这正是死亡三要素凑齐的场景。

**符号说明**：$r,s'$ 是从离线记录中拿到的即时奖励和下一状态，$\gamma$ 是折扣因子；$a'$ 是下一状态的候选动作，$Q(s',a')$ 是它的估值。$\max_{a'}$ 比较候选动作，并不局限于该记录里实际做过的动作。

代表方法（三种思路，必能各说一句话）：
1. **BCQ（约束策略空间）**：训一个生成模型拟合数据分布，只在"像数据"的动作里取 max，物理上避免查 OOD 动作；
2. **CQL（保守价值）**：在 Q 学习目标里显式惩罚 OOD 动作的 Q 值、抬高数据内动作的 Q 值 → 学到的 Q 对未知动作"悲观"，防止高估；
3. **IQL（完全避开 OOD 查询）**：从不做 max，用 **expectile 回归**（τ 取 0.7~0.9 的非对称最小二乘）让 V 逼近 Q 的高分位数，再用 advantage-weighted regression 提取策略——整个流程只对数据内的动作做监督学习，所以非常稳。

**与自动驾驶的连接**：路测日志就是天然的离线数据集，不能交互探索 → offline RL / IL 是自动驾驶数据闭环的天然框架。

**一句话总结**：offline RL 的病根是"对没见过的动作盲目乐观"，所有方法都在教价值函数"对未知保持悲观"。

## Q2 ★★★ RLHF 全流程？DPO/GRPO 和 PPO 什么关系？（LLM 时代必问）

**标准答案**

RLHF 三步：
1. **SFT**：人工标注示范，监督微调出初始策略 $\pi_{\mathrm{SFT}}$；
2. **奖励模型（RM）**：人工对同一 prompt 的两个回答做成对比较，用 Bradley-Terry 模型训练：$L=-\log\sigma(r_{\mathrm{win}}-r_{\mathrm{lose}})$，即把"胜率"建模为两个回答奖励差的 logistic；

   **符号说明**：$r_{\mathrm{win}}$ 和 $r_{\mathrm{lose}}$ 分别是奖励模型给人类偏好、未偏好回答打的分。$\sigma$ 是把分差变成偏好概率的 sigmoid 函数，$L$ 是这对样本的负对数似然损失。

3. **PPO 优化**：最大化 $\mathbb{E}[r_{\mathrm{RM}}(x,y)]-\beta D_{\mathrm{KL}}(\pi\Vert\pi_{\mathrm{ref}})$——KL 项锚定参考策略，防止 reward hacking（钻 RM 漏洞输出高分但无意义文本）和模式坍塌。

   **符号说明**：$x$ 是输入提示，$y$ 是模型生成的回答，$r_{\mathrm{RM}}(x,y)$ 是奖励模型给这个回答的分数，$\mathbb{E}$ 对提示及生成的回答取平均。$\pi$ 是训练中的策略，$\pi_{\mathrm{ref}}$ 是固定的参考策略，$D_{\mathrm{KL}}$ 衡量二者的分布差异，$\beta$ 调节偏离参考策略的惩罚强度。

后续演化（被追问时答）：
- **DPO**：利用"KL 正则下最优策略有闭式解 $\pi^*(y\mid x)\propto\pi_{\mathrm{ref}}(y\mid x)\exp(r(x,y)/\beta)$"，反解出 $r$ 代回 RM 损失 → 直接在偏好数据上做监督学习，免 RM、免在线采样、免 PPO；代价是失去在线探索和显式奖励信号；

  **符号说明**：$x,y$ 是提示和候选回答，$\pi^*(y\mid x)$ 是目标下的最优回答分布，$\pi_{\mathrm{ref}}(y\mid x)$ 是参考分布。$r(x,y)$ 是该回答的奖励，$\beta$ 是 KL 正则系数；$\exp$ 把奖励变成相对于参考分布的权重，$\propto$ 表示右侧还需对同一提示的所有回答归一化。

- **GRPO**：PPO 的简化——去掉 critic，同一 prompt 采一组（group）回答，用**组内相对奖励**（减均值除标准差）当 advantage；省显存、实现简单，DeepSeek-R1 用它做推理能力 RL。

**加分串联**：RLHF 的"SFT 先验 + RL 优化 + KL 锚定"，与自动驾驶"IL + RL 微调 + 行为克隆正则"、VLA + GRPO 后训练，是同一个数学范式在不同领域的三次复现——面试主动指出这一点。

**一句话总结**：RLHF = 人类偏好蒸成奖励模型，PPO 在 KL 缰绳下优化；DPO/GRPO 是它的"去 RL 化"与"去 critic 化"简化。

## Q3 ★ Decision Transformer 的核心思想与局限？

**标准答案**

思想：把 RL 从"学价值/策略"转成**条件序列建模**——轨迹排成 $(\hat{R}_1,s_1,a_1,\hat{R}_2,s_2,a_2,\ldots)$ 序列（$\hat{R}$ 是 return-to-go，未来回报目标），用 GPT 自回归训练 $a_t\sim\pi(\cdot\mid s_t,\hat{R}_t,\text{历史})$；推理时给定一个高目标回报，模型"照着目标演"。

**符号说明**：$t$ 是时间步，$s_t,a_t$ 是该步的状态和动作；$\hat{R}_t$ 是从该步开始的剩余回报，训练时从轨迹计算，推理时作为目标输入。$\pi$ 是条件动作模型，$\sim$ 表示动作来自这个分布；条件还包括当前步之前的序列信息。

优点：无 bootstrapping → 避开死亡三要素，训练像监督学习一样稳定；天然吃 offline 数据；能吸收 Transformer 生态。

局限：
- 不做 stitching（难以把两条次优轨迹的优点拼成更优策略，价值方法天然会）；
- 依赖"目标回报"的条件标定，怎么设目标本身是个问题；
- 随机性强的环境中，回报高可能只是运气好，条件模仿会把运气当实力。

**一句话总结**：DT 用"照着剧本演"替代"算账"，换来稳定，丢了 stitching。

## Q4 ★ Model-based RL 的代表工作线？

**标准答案**

- **Dyna**：真实数据学模型，模型生成假想数据混进训练，一份数据两份用；
- **Dreamer（V1~V3）**：学一个 latent world model（编码观测 → 预测奖励/继续/转移），actor-critic 完全在模型的"想象 rollout"里训练；V3 用一套固定超参打通 Atari、控制、Minecraft 等 150+ 任务，关键技术包括 symlog 变换、categorical critic；
- **MuZero**：模型不学重建观测，只学预测**对决策有用的三样东西**（value、policy、reward），配合 MCTS 搜索；不需要知道规则就能下围棋/象棋/打 Atari。

自动驾驶视角：world model 是当前热点——生成式场景模型（如 GAIA-1 类工作）可以作为"可微分、可控的闭环仿真器"，让 RL/规划在想象里训练和评测，绕开真实路测的成本与安全限制。

**一句话总结**：model-based 的进化方向是"模型越学越抽象"——从重建像素，到只预测决策需要的量。

## Q5 ★ 多智能体 RL（MARL）的核心挑战与代表方法？

**标准答案**

核心挑战：
1. **非平稳性**：其他智能体也在学，对每个个体而言环境分布在变 → 单智能体算法的收敛保证全部失效；
2. **信用分配**：团队奖励怎么分到每个智能体；
3. **维度爆炸**：联合动作空间随智能体数指数增长。

代表方法：
- **MADDPG**：集中训练、分散执行（CTDE）——critic 看全局信息（所有智能体状态动作），actor 只看本地观测；
- **MAPPO**：把 CTDE 思想搬到 PPO，实践效果极好，成为合作 MARL 默认基线；
- **QMIX**：值分解——团队 Q 分解为个体 Q 的单调混合。

应用：多车博弈/路口协同、机器人足球、游戏 AI。

**一句话总结**：MARL 的一切麻烦来自"别人也在学"，CTDE 是工程上最成功的解法。

## 模板二：经典 RL 课程项目（DQN/PPO 打 gym 环境）

讲消融："我实现了 DQN 并做了消融实验——去掉 replay 后训练震荡发散（验证了样本相关性问题），去掉 target network 后 Q 值爆炸（验证了 bootstrap 自激），这让我对死亡三要素有了实操理解。"——**讲消融比讲结果值钱**。

## 讲述原则

1. 永远先说**问题和动机**，再说方法，再说数字；
2. 数字要具体（episode length、收敛迭代数、训练时长、硬件）；
3. 主动讲一个**踩坑—定位—修复**的故事（done 的 bootstrap 处理、reward hacking 实例），这是区分"跑过 demo"和"真做过"的分水岭；
4. 结尾主动说 limitation 和下一步（如"只在仿真验证，sim2real 还差 actuator modeling"），显得诚实且有判断力。

# 九、快问快答 30 条（一句话答案）

1. **γ 一般取多少？** 0.99/0.995，有效视野约为 $1/(1-\gamma)$ 步。
2. **DQN 为什么过估计？** max 操作对带噪估计取最大，期望上偏正（Double DQN 由此而来）。
3. **PPO 的 clip ε 取多少？** 0.2。
4. **SAC 的目标熵？** $-\dim(A)$（动作维度的负值）。
5. **TD3 比 DDPG 多了什么？** 双 Q 取 min、actor 延迟更新、目标动作平滑加噪。
6. **on-policy 最大缺点？** 样本效率低，数据用一次就扔。
7. **baseline 的作用？** 降方差，不改变梯度期望。
8. **GAE 的 λ 两端是什么？** $\lambda=0$ 是单步 TD（低方差有偏），$\lambda=1$ 接近 MC（无偏高方差）。
9. **HER 适用于什么？** goal-conditioned 稀疏奖励任务（把失败轨迹改成"另一个目标的成功"）。
10. **ε-greedy 怎么衰减？** 线性或指数衰减，如 1.0 → 0.05，训练前期多探索。
11. **PPO 为什么要归一化 advantage？** 稳定梯度尺度，防止个别大优势样本主导更新。
12. **value loss 为什么也要 clip？** 防止 critic 一步更新过大，配合 actor 的 trust region。
13. **done 信号最经典的坑？** 超时截断（time-limit）当终止处理 → 漏加 $\gamma V(s')$，也就是打折后的下一状态估值，价值系统性失真。
14. **DDPG 为什么用 OU 噪声？** 时序相关的探索适合物理控制（纯高斯抖动被动力学低通滤掉）。
15. **SAC/PPO 动作为什么用 tanh squash？** 限幅到合法范围，防止动作饱和物理系统；log-prob 记得加 Jacobian 修正。
16. **soft update 的 τ？** 0.005 左右，$\theta^-\gets\tau\theta+(1-\tau)\theta^-$。

    **符号说明**：$\theta$ 是在线参数，$\theta^-$ 是目标参数，$\tau$ 是每次从在线参数混入的比例。

17. **Double DQN 解什么？** 解耦动作选择（在线网络）与价值评估（目标网络），治过估计。
18. **Dueling 结构的好处？** V 和 A 分流，无动作差异的状态也能学 V，泛化更好。
19. **PER 引入的偏差怎么修？** importance sampling 权重 $w_i=\bigl(1/[N P(i)]\bigr)^\beta$。

    **符号说明**：$i$ 是样本编号，$N$ 是回放池当前的样本总数，$P(i)$ 是优先采样时抽到样本 $i$ 的概率，$\beta$ 是纠偏强度，$w_i$ 是该样本训练时的权重。

20. **CQL 一句话？** 压低 OOD 动作的 Q，让价值函数对未知动作悲观。
21. **IQL 的 τ 是什么？** expectile 参数（0.7~0.9），让 V 逼近 Q 的高分位数，全程不查 OOD 动作。
22. **DPO 和 PPO 的关系？** DPO 是 KL 正则 RLHF 的闭式解版本，免 RM、免在线采样。
23. **探索的三个层次？** 动作噪声（ε-greedy/高斯）→ 参数噪声（NoisyNet）→ 内在动机（ICM/RND）。
24. **reward hacking 例子？** 给姿态奖励，机器人原地站住不动；给抬腿奖励，原地踏步。
25. **potential-based shaping 公式？** $F(s,a,s')=\gamma\Phi(s')-\Phi(s)$，保证最优策略不变。

    **符号说明**：$F$ 是额外奖励，$s,a,s'$ 是当前状态、动作、下一状态，$\Phi$ 是状态的势函数，$\gamma$ 是原任务的折扣因子。

26. **PPO 训练中 KL 多大算异常？** 远超 target KL（0.01~0.015 量级）就该 early stop 或降 lr。
27. **explained variance 说明什么？** critic 拟合质量；≈1 健康，≈0 说明 actor 在听噪声。
28. **为什么 critic 可以吃特权信息？** critic 只参与训练不进部署，随便喂（asymmetric actor-critic）。
29. **MCTS 四步？** 选择（UCB）→ 扩展 → 模拟/评估 → 回传。
30. **RL 三大难点？** 信用分配、探索-利用、数据分布随策略变化。
